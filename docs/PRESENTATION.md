## 答辩准备

- **为什么颜色通道要联合阈值？** 课程目标按像素位置计数，任一通道或方向非零就算该位置有梯度；逐通道阈值会改变模型。
- **为什么能用 FFT？** 周期差分使固定 h、v 后的线性算子在傅里叶域对角化，原来的矩阵求解变为逐频率相除。
- **为什么不能每轮裁剪到 [0,1]？** 闭式解对应无额外值域约束的二次子问题，循环内裁剪会改变更新；保存显示图时才处理值域。
- **迭代更多是否一定更好？** 不能保证，整体目标非凸，kappa 影响求解路径和开销。
- **边缘数量越少越好吗？** 不一定，全部抹掉也会减少边缘，所以还要检查参考轮廓覆盖和局部结果。
- **干净图是否被用于恢复？** 只用于生成压缩输入和计算指标，优化只看到解码 JPEG。
- **PSNR 与 SSIM 为什么可能不一致？** 一个按像素误差衡量，一个按局部亮度、对比度和结构衡量，局部结构变化可能使结论不同。
- **如何定位一次开发改动？** 查看本地 COMMIT_LOG 中的完整 hash，再执行 `git show <hash>`；AI_LOG 记录对应采用、修正与验证过程。
