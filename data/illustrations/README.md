# 第一阶段实验输入

三幅插画由本项目 `experiment_smoothing.py` 的 `make_illustrations()` 生成，
不使用外部图片，无随机过程：

- `gray_step`：带细密纹理的灰度阶跃边界。
- `color_landscape`：太阳、草地和房屋组成的彩色插画。
- `color_shapes`：圆、方块和细线组成的彩色几何插画。

每组包含干净结构 `*_clean.png` 与叠加周期细纹理的 `*_input.png`。
纹理浮点幅度为 0.025，图像大小 192 × 128；输入保存为 8 位 PNG 后重新载入再平滑。
干净图只用于实验误差参考，不参与优化。

这些插画用于检查低幅度纹理和清晰边界，不能代表自然照片上的全部表现。
