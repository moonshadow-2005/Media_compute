# 结构平滑辅助边缘提取

三组输入均使用 lambda=0.02、kappa=2、beta_max=100000，22 次迭代。
两路检测均为 OpenCV Canny：low=20、high=40、apertureSize=3、L2gradient=True。
RGB 转灰度，不额外模糊；参数与预处理保持一致，避免通过调整阈值制造差异。

| 输入 | 原图边缘像素 | 平滑后边缘像素 | 偏离参考轮廓的像素（前→后） | 参考轮廓覆盖率（前→后） |
|---|---:|---:|---:|---:|
| 灰度阶跃 | 6162 | 128 | 5971 → 0 | 100% → 100% |
| 彩色风景 | 11840 | 544 | 11170 → 0 | 100% → 100% |
| 彩色几何 | 11799 | 522 | 11214 → 0 | 100% → 100% |

参考是干净人工插画的同参数 Canny，允许 1 像素位置偏移，不是人工标注真值。
这些输入特意叠加低幅度高频纹理，因此原图会出现大量纹理边缘；
平滑后细纹理边缘大幅减少，主要阶跃、房屋和图形轮廓仍保留。
边缘数量减少本身不足以证明效果更好，因此同时记录参考轮廓覆盖率，并查看四面板对照图。

结论限于这些人工插画。真实图像中微弱轮廓可能与纹理一起被抹除；灰度 Canny 也可能漏掉
亮度接近但颜色不同的边界。较大的 lambda 会合并小结构，见结构平滑实验中的失败现象。

复现：在项目根目录运行 `python3 experiment_edges.py --output results/edges_rerun`。
每个子目录包含输入、平滑图、边缘图、原始浮点输出以及全部运行参数和耗时。
检测器接口依据：[OpenCV Canny 文档](https://docs.opencv.org/4.13.0/da/d22/tutorial_py_canny.html)。
